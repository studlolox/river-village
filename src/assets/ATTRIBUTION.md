# Asset Attribution & Provenance — River Village

All shipped assets in `src/` are 100% original or procedural:

- **3D Meshes & Textures:** Procedurally generated at runtime using `three.js` geometries and HTML5 Canvas textures (`src/js/render/`).
- **Audio & SFX:** Synthesized at runtime using the Web Audio API (`src/js/render/audio.js`).
- **Icons & Manifest Art:** Original SVG/PNG icons generated for River Village (`src/assets/icons/`).
- **Fonts:** System UI font stack (no external font CDNs).

No `.xnb`, `.xwb`, `.xsb`, or copyrighted reference assets from `extracted-assets/` are shipped in `src/` or `dist/`.
